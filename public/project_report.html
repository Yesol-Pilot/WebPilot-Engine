11. 핵심 알고리즘 & 수식

🔍 시맨틱 검색 - 코사인 유사도 (Cosine Similarity)

768차원 임베딩 벡터 간의 의미적 유사도를 계산합니다. 값 범위는 -1 ~ 1이며, 1에 가까울수록 의미가 유사합니다.

$$\text{similarity}(A, B) = \cos(\theta) = \frac{A \cdot B}{\|A\| \|B\|} = \frac{\sum_{i=1}^{n} A_i B_i}{\sqrt{\sum_{i=1}^{n} A_i^2} \cdot \sqrt{\sum_{i=1}^{n} B_i^2}}$$

📊 렉시컬 검색 - BM25 (Best Matching 25)

키워드 기반 검색 알고리즘. TF-IDF의 개선 버전으로, 문서 길이 정규화를 적용합니다.

$$\text{score}(D, Q) = \sum_{i=1}^{n} \text{IDF}(q_i) \cdot \frac{f(q_i, D) \cdot (k_1 + 1)}{f(q_i, D) + k_1 \cdot (1 - b + b \cdot \frac{|D|}{\text{avgdl}})}$$
f(q_i, D) 문서 D에서 쿼리 단어 q_i의 빈도
|D| 문서 길이
avgdl 평균 문서 길이
k_1 = 1.5, b = 0.75 튜닝 파라미터

🔀 하이브리드 검색 - RRF (Reciprocal Rank Fusion)

Vector 검색과 BM25 검색 결과를 융합하여 최종 랭킹을 결정합니다.

$$\text{RRF}(d) = \sum_{r \in R} \frac{1}{k + r(d)}$$

k = 60은 상위 순위에 과도한 가중치를 방지합니다. Vector(70%) + BM25(30%) 가중치 결합.

🌲 공간 배치 - MCTS (Monte Carlo Tree Search)

충돌 없는 최적 오브젝트 배치를 탐색합니다. 탐색(Exploration)과 활용(Exploitation)의 균형을 맞춥니다.

$$\text{UCB1} = \bar{X}_j + C \sqrt{\frac{\ln N}{n_j}}$$
X̄_j 노드 j의 평균 보상 (배치 품질 점수)
N 부모 노드 방문 횟수
n_j 자식 노드 j 방문 횟수
C = √2 탐색 상수

📦 충돌 감지 - BVH (Bounding Volume Hierarchy)

O(log n) 시간 복잡도로 충돌을 감지합니다. 모든 축(x, y, z)에서 AABB가 겹치면 충돌입니다.

$$\text{AABB Overlap} = (A_{min} \leq B_{max}) \land (A_{max} \geq B_{min})$$

🛡️ 시맨틱 가드레일 - 중복 생성 방지

쿼리 컨셉과 기존 에셋의 유사도가 임계값(θ = 90%) 이상이면 중복으로 판단하여 AI 생성을 차단합니다.

$$\text{isDuplicate} = \text{similarity}(q, \text{bestMatch}) \geq \theta_{threshold}$$
