🧮 핵심 알고리즘 & 수식

시스템의 핵심 로직을 구성하는 알고리즘과 수학적 기반

시맨틱 검색 - 코사인 유사도 (Cosine Similarity)

$$\text{similarity}(A, B) = \cos(\theta) = \frac{A \cdot B}{\|A\| \|B\|} = \frac{\sum_{i=1}^{n} A_i B_i}{\sqrt{\sum_{i=1}^{n} A_i^2} \cdot \sqrt{\sum_{i=1}^{n} B_i^2}}$$

768차원 임베딩 벡터 간의 의미적 유사도를 계산합니다. 값 범위는 -1 ~ 1이며, 1에 가까울수록 의미가 유사합니다. 

function cosineSimilarity(a: number[], b: number[]): number {
    let dotProduct = 0, normA = 0, normB = 0;
    for (let i = 0; i < a.length; i++) {
        dotProduct += a[i] * b[i];
        normA += a[i] * a[i];
        normB += b[i] * b[i];
    }
    return dotProduct / (Math.sqrt(normA) * Math.sqrt(normB));
}

렉시컬 검색 - BM25 (Best Matching 25)

$$\text{score}(D, Q) = \sum_{i=1}^{n} \text{IDF}(q_i) \cdot \frac{f(q_i, D) \cdot (k_1 + 1)}{f(q_i, D) + k_1 \cdot (1 - b + b \cdot \frac{|D|}{\text{avgdl}})}$$
  • f(q_i, D) = 문서 D에서 쿼리 단어 q_i의 빈도
  • |D| = 문서 길이, avgdl = 평균 문서 길이
  • k_1 = 1.5, b = 0.75 (튜닝 파라미터)
  • IDF(q_i) = 역문서빈도 = log((N - n(q_i) + 0.5) / (n(q_i) + 0.5))

하이브리드 검색 - RRF (Reciprocal Rank Fusion)

$$\text{RRF}(d) = \sum_{r \in R} \frac{1}{k + r(d)}$$

Vector 검색과 BM25 검색 결과를 융합하여 최종 랭킹을 결정합니다. k = 60은 상위 순위에 과도한 가중치를 방지합니다. 

// Vector(70%) + BM25(30%) 가중치 결합
const vectorWeight = 0.7;
const bm25Weight = 0.3;
const k = 60;

function calculateRRF(vectorRank: number, bm25Rank: number): number {
    return vectorWeight * (1 / (k + vectorRank)) 
         + bm25Weight * (1 / (k + bm25Rank));
}

공간 배치 - MCTS (Monte Carlo Tree Search)

$$\text{UCB1} = \bar{X}_j + C \sqrt{\frac{\ln N}{n_j}}$$

충돌 없는 최적 오브젝트 배치를 탐색합니다. 탐색(Exploration)과 활용(Exploitation)의 균형을 맞춥니다.

  • X̄_j = 노드 j의 평균 보상 (배치 품질 점수)
  • N = 부모 노드 방문 횟수
  • n_j = 자식 노드 j 방문 횟수
  • C = √2 = 탐색 상수
// MCTS 4단계: Selection → Expansion → Simulation → Backpropagation
interface MCTSNode {
    position: Vector3;      // 배치 위치 후보
    score: number;          // 누적 보상
    visits: number;         // 방문 횟수
    children: MCTSNode[];   // 자식 노드
}

충돌 감지 - BVH (Bounding Volume Hierarchy)

$$\text{AABB Overlap} = (A_{min} \leq B_{max}) \land (A_{max} \geq B_{min})$$

O(log n) 시간 복잡도로 충돌을 감지합니다. 모든 축(x, y, z)에서 AABB가 겹치면 충돌입니다. 

function checkAABBCollision(a: BoundingBox, b: BoundingBox): boolean {
    return (a.min.x <= b.max.x && a.max.x >= b.min.x) &&
           (a.min.y <= b.max.y && a.max.y >= b.min.y) &&
           (a.min.z <= b.max.z && a.max.z >= b.min.z);
}

시맨틱 가드레일 - 중복 생성 방지

$$\text{isDuplicate} = \text{similarity}(q, \text{bestMatch}) \geq \theta_{threshold}$$

쿼리 컨셉과 기존 에셋의 유사도가 임계값(θ = 0.9, 90%) 이상이면 중복으로 판단하여 AI 생성을 차단합니다. 

async function checkSemanticDuplicate(concept: string, threshold = 0.9) {
    const results = await hybridSearch(concept, 1);
    if (results[0]?.similarity >= threshold) {
        return { isDuplicate: true, existingUrl: results[0].path };
    }
    return { isDuplicate: false };
}

스케일 추론 - World-Relative Sizing

$$\text{Scale}_{object} = \frac{\text{RealWorldSize}_{object}}{\text{ReferenceUnit}} \times \text{SceneModifier}$$

오브젝트의 실제 크기를 기준으로 상대적 스케일을 계산합니다. 참조 단위는 1m = 1 unit입니다.

  • person = 1.7m → scale 1.7
  • chair = 0.9m → scale 0.9
  • castle = 30m → scale 30.0
  • candle = 0.2m → scale 0.2
