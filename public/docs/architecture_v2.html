요약 Executive Summary

WebPilot Engine은 사용자의 텍스트 프롬프트를 입력받아 완전한 3D 인터랙티브 씬을 자동 생성하는 AI-Native 씬 제너레이션 플랫폼이다. Next.js 14 + React Three Fiber 기반의 웹 애플리케이션으로, Gemini LLM, Tripo 3D, 시맨틱 벡터 검색, MCTS 배치 알고리즘, 7단계 검증 프로토콜을 결합하여 프로덕션 수준의 3D 콘텐츠를 생산한다.

✅ 핵심 미션

"텍스트 한 줄로 완전한 3D 세계를 창조한다" — 하드코딩된 규칙 대신 AI가 모든 의사결정을 동적으로 수행하며, 시맨틱 검색 + MCTS 기반 최적 배치로 물리적으로 타당한 씬을 자율 생성합니다.

1 시스템 아키텍처

1.1 Director-Architect-Renderer Triad

🎬
Director Agent
시나리오 해석 → 장면 명세서 생성. Gemini LLM으로 프롬프트를 분석하여 오브젝트 목록, 조명, 분위기를 결정. 전역 최적화 담당.
📐
Architect Agent
MCTS 기반 충돌 없는 배치 계산. Poisson Disk Sampling + BVH 공간 분할로 물리적으로 타당한 좌표를 산출. 지역 최적화 담당.
🎨
VisualCore Agent
Three.js 렌더링 실행 및 리소스 적용. GLB 로딩, 조명 프리셋, 파티클 이펙트, 포스트 프로세싱, BGM 자동 재생. 렌더링 담당.

2 AI 씬 생성 파이프라인

사용자 프롬프트로부터 3D 씬이 생성되는 전체 파이프라인은 6단계(Stage)로 구성되며, 각 단계는 독립적으로 폴백(fallback)을 지원한다.

2.1 Stage 1-2: 프롬프트 → 시나리오 생성

💡 프롬프트 확장 (Prompt Enrichment)

사용자 입력 "호그와트 대연회장"이 PromptEnrichmentService를 통해 "해리포터 세계관의 호그와트 마법학교 대연회장, 떠다니는 촛불, 별이 빛나는 천장, 네 기숙사 긴 테이블"로 확장됩니다.

  • ScenePlanner (22.7KB): Gemini LLM으로 JSON 스키마 기반 장면 명세서 생성
  • SemanticCacheService (18.4KB): 의미적 유사도 기반 캐싱으로 중복 API 호출 방지
  • VectorSearchService (26.7KB): Gemini Embedding으로 시맨틱 검색 수행

2.2 Stage 3-4: 시맨틱 에셋 매칭

생성된 오브젝트 목록은 3계층 보호 프로토콜을 통해 최소 비용으로 에셋을 확보한다:

  1. Layer 1: 로컬 에셋 라이브러리 — 1,676+ GLB 파일 중 키워드 매칭 (비용: 0원)
  2. Layer 2: DB 캐시 — 이전 생성 결과의 시맨틱 유사도 검색 (비용: 0원)
  3. Layer 3: 외부 API 생성 — Tripo 3D / Hyper3D API 호출 (비용: 크레딧 소모)

2.3 Stage 5-6: MCTS 최적 배치

오브젝트 배치는 Monte Carlo Tree Search (MCTS) 알고리즘을 활용하여 최적의 위치를 탐색한다. BVH (Bounding Volume Hierarchy) 공간 분할로 O(log N) 충돌 감지를 달성하며, Poisson Disk Sampling으로 자연스러운 분포를 생성한다.

🌳
BVH 공간 분할
AABB 기반 바운딩 볼륨 계층 구조. O(N²) → O(N log N) 충돌 검사 최적화. BVHTree.ts (555줄)
🎯
Poisson Disk Sampling
최소 거리 보장 균일 랜덤 배치. 15가지 프리셋 (forest, urban, scattered 등)

3 검증 에이전트 프로토콜 v2.0

생성된 씬의 품질을 보증하기 위해 3-Tier 7-Agent 검증 시스템이 순차적으로 실행된다. Fail-Fast 원칙에 따라 하위 Tier 통과 시에만 상위 Tier를 실행하여 자원을 절약한다.

3.1 Tier 0: 물리/규칙 검증 (Fast & Cheap)

📍
PlacementValidator
BVH 기반 충돌 감지, 바닥 접촉 검증, 경계 이탈 검사. Auto-Fix: 바닥 스냅, 충돌 분리. 21KB
⚡
PerformanceValidator
폴리곤 수 제한, Draw Call 검사, 텍스처 메모리 분석, 재질 비용 계산. 20KB

3.2 Tier 1: 시맨틱 검증 (Semantic)

🎯
ObjectValidator
테마 적합성 (Gemini 평가), 오브젝트 중복 검사, 시맨틱 역할 일관성. 14.6KB
📖
ScenarioValidator
프롬프트-시나리오 일치도, 시간/환경/분위기 일관성, 필수 오브젝트 존재 확인. 16.2KB

3.3 Tier 2: 경험/시각 검증 (Experience)

🗺️
NavigationValidator
NavMesh 그리드 + A* 경로 탐색. 스폰 포인트 → 주요 지점 도달 가능성 검증. 17.8KB
🎨
AestheticsValidator
구도/균형/색채 분석, 테마 비주얼 일관성, VLM 기반 시각 품질 평가. 18KB

QualityGate 통합 판정기

QualityGate.ts (12.3KB)는 모든 검증기의 결과를 가중치 기반으로 통합하여 최종 PASS/NEEDS_REVISION/REJECT 판정을 내린다. Auto-Fix 적용 후 재시도(최대 2회)를 지원한다.

검증기 가중치 임계값 Auto-Fix
PlacementValidator 25% 70점 ✅ 바닥 스냅, 충돌 분리
PerformanceValidator 20% 60점 ✅ 스케일 조정
ObjectValidator 15% 50점 ❌
ScenarioValidator 15% 50점 ❌
NavigationValidator 15% 40점 ❌
AestheticsValidator 10% 40점 ❌

4 상태 관리: Zustand SSOT

전체 애플리케이션 상태는 Zustand 슬라이스 패턴으로 Single Source of Truth (SSOT)을 구현한다. 각 도메인은 독립된 슬라이스로 분리되며, gameStore.ts에서 통합된다.

슬라이스 역할 핵심 상태
aiScene AI 생성 씬 데이터 objects, bgmUrl, lighting, particles, postProcessing
gameSlice 게임 플레이 상태 scenario, genre, gameType, loaded
uiSlice UI 상태 activePanel, notifications, loading
worldSlice 월드 파티셔닝 voronoi cells, player position

7 에셋 파이프라인

📦
Layer 1: 로컬 라이브러리
1,676+ GLB, 62 SFX, 다수의 스카이박스. Sketchfab CC0 + 자체 생성. 비용 0원
💾
Layer 2: DB 캐시
Prisma + SQLite DB. 이전에 생성된 에셋의 시맨틱 유사도 재활용. 비용 0원
🌐
Layer 3: API 생성
Tripo 3D, Hyper3D, Blockade Labs (스카이박스), ElevenLabs (SFX). 크레딧 소모

에셋 처리 파이프라인

  • 스캐닝: indexer/scanner.ts — public/models 전체 스캔 (GLB/GLTF/FBX)
  • 분석: AssetMetadataService.ts — gltf-transform 기반 딥 분석 (폴리곤, 텍스처, 애니메이션)
  • 태깅: 다차원 태그 시스템 (style, material, era, mood) — 257개+ 에셋 색인
  • 최적화: AssetOptimizer.ts — Draco 압축, 중복 제거, 텍스처 리사이즈
  • 저장: Cloudflare R2 + Prisma DB 메타데이터 동기화
