## 5. 인사이트 (Insights)

### 배운 점

- Web Audio API의 `OscillatorNode`와 `GainNode` 조합으로 간단한 효과음 생성 가능
- R3F의 `bufferAttribute`는 `args` prop으로 초기화해야 타입 오류 방지
- 동적 import (`import()`)를 활용하면 서버 컴포넌트에서도 클라이언트 전용 모듈 사용 가능

### 개선점

- 스트릭 카운터가 현재 인메모리 → Redis 등 영구 저장소로 전환 필요
- CSS inline style lint 경고 다수 존재 → 향후 리팩토링 예정
