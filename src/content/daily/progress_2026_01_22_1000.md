# [Progress] Layer 1 로컬 에셋 매칭 활성화

## 완료된 작업

### 1. 문제 진단

- **원인**: `ResourceMatcher.ts`의 `matchAsset()` 함수가 `return null` 하드코딩
- **영향**: 모든 매칭 요청이 API로 직행 → 5회 한도 도달 시 플레이스홀더만 표시

### 2. Layer 1 매칭 복구

- **해결**: `findAssetByKeyword` 호출 추가로 `/public/models` 에셋 우선 매칭
- **결과**: 라이브러리 히트 시 API 호출 없이 즉시 GLB 로드

### 3. 브라우저 검증

- **테스트**: "고대 책장" 프롬프트
- **결과**: `antiquebookshelf_02.glb` 매칭 성공, 실제 모델 렌더링 확인
