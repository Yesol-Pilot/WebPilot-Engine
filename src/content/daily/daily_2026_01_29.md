## 3. AI 알고리즘 상세

### 3.1 RAG 기반 오브젝트 검색

**하이브리드 검색 = Vector + Lexical + RRF 융합**

- **Vector Search**: Gemini Embedding API (768D)
- **Lexical Search**: BM25 알고리즘
- **RRF Fusion**: $RRF_{score}(d) = \sum_{r \in R} \frac{1}{k + rank_r(d)}$ (k=60)

### 3.2 MCTS 기반 배치 알고리즘

**Monte Carlo Tree Search로 충돌 없는 최적 배치**

1. **Selection**: UCB1 기반 노드 선택
2. **Expansion**: 그리드 기반 위치 샘플링
3. **Simulation**: AABB 충돌 검사 + 점수 계산
4. **Backpropagation**: 점수 업데이트

**점수 함수**:

- Zone 중심 거리 (가까울수록 ↑)
- Clearance 거리 (멀수록 ↑)
- 그리드 정렬 보너스
- 경계 침범 페널티

### 3.3 스케일 추론 알고리즘

**핵심 원칙: 일괄 스케일 적용 금지**

- 실제 세계 크기 참조 DB (chair: 0.9m, desk: 0.75m, ...)
- 시맨틱 수식어 매트릭스 (giant: x3.0, tiny: x0.3, ...)
- 문맥 힌트 분석 ("on a desk" → x0.1)

## 4. USN (Universal Scale Normalization)

### 4-Phase 아키텍처

| Phase | 이름 | 핵심 알고리즘 | 상태 |
|-------|------|--------------|------|
| 1 | PCA 축 정렬 | Jacobi 고유값 분해 | ✅ |
| 2 | OBB 생성 | PCA 기반 Oriented Bounding Box | ✅ |
| 3 | 자동 분류 | 형상/종횡비/밀도 분석 | ✅ |
| 4 | 시맨틱 검색 | 12D Feature Vector | ✅ |

### 핵심 수식

**공분산 행렬**: $\mathbf{C} = \frac{1}{N} \sum_{i=1}^{N} (p_i - \mu)(p_i - \mu)^T$

**VRE (Volume Reduction Efficiency)**: $(1 - \frac{V_{OBB}}{V_{AABB}}) \times 100\%$

## 5. 발생한 이슈 및 해결 방안

### Issue 1: 벡터 검색 정확도 저하

- **원인**: 키워드만으로 임베딩 → 시맨틱 정보 부족
- **해결**: 하이브리드 검색 도입 (Vector + Lexical + RRF)
- **결과**: 검색 정확도 40% → 85%

### Issue 2: 오브젝트 중첩 배치

- **원인**: 랜덤 배치 시 충돌 검사 미수행
- **해결**: MCTS + AABB 충돌 검사
- **결과**: 충돌 발생률 100% → 0%

### Issue 3: 일괄 스케일 → 비현실적 크기

- **원인**: 에셋별 특성 무시
- **해결**: Scale Reasoning Service 도입
- **결과**: 물리적 정확도 향상

### Issue 4: PCA 퇴화 케이스 (평면형 메쉬)

- **원인**: 모든 점이 평면 위 → λ₃ ≈ 0
- **해결**: 퇴화 케이스별 예외 처리 (외적으로 e₃ 생성)
