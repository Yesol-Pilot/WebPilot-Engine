## 🔧 GLB 메타데이터 설정 방법

```json
{
  "lighting": {
    "exposure": -2.0,
    "environmentIntensity": 0.0,
    "ambientIntensity": 0.0
  }
}
```

| 값 | 효과 |
|----|------|
| `environmentIntensity: 0.0` | 환경광 완전 비활성화 (어두운 실내) |
| `environmentIntensity: 0.5` | 기본값 (중간 밝기) |
| `environmentIntensity: 1.0` | 최대 환경광 (야외 환경) |
